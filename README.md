# WorldDB

Uma exploração ilustrada de seis capítulos da história como se fossem registros de um banco de dados. O prólogo do Jardim do Éden é identificado como narrativa religiosa.

## Iniciar localmente

```bash
npm install
npm run dev
```

Abra o endereço `Local` exibido pelo Vite no terminal.

## Compilar

```bash
npm run build
npm run preview
```

Os capítulos ficam em `src/data.ts`. IDs, entidades, relações e SQL são metáforas criadas para o site; as fontes históricas aparecem no rodapé da interface.
